# AniLiberty TV

**AniLiberty TV 1.0.2** — неофициальный клиент сервиса AniLiberty для телевизоров Samsung с Tizen 6.0 и новее.

Приложение управляется пультом телевизора и позволяет просматривать каталог и серии аниме, открывать связанные тайтлы, а после авторизации — пользоваться историей просмотров, продолжением просмотра и избранным.

**Неофициальный клиент.** AniLiberty TV — независимый проект. Он не является официальным приложением AniLibria или AniLiberty. Команды AniLibria и AniLiberty не участвуют в разработке, распространении и поддержке клиента.

Приложение создано с помощью **ChatGPT (OpenAI)**.

## Что нового в 1.0.2

- Полное описание тайтла по кнопке «Подробнее»; компактное описание — пять строк с выравниванием по ширине.
- Улучшена навигация с пульта: плавный возврат к началу страницы и последовательный переход между кнопками и сериями.
- В верхней панели — индикатор состояния синхронизации с возможностью ручного обновления. Подробности обмена данными — в правой части страницы «Аккаунт».
- Автоматическая проверка отправленных отметок просмотра и таймкодов на сайте.
- В плеере можно скрыть или показать панель кнопками ↑/↓; пропуск опенинга/эндинга доступен через OK или →, а вместо отдельной кнопки показана подсказка.
- При бездействии 5 минут в меню или на паузе включается тёмная защитная заставка с медленно перемещающимся логотипом. Во время воспроизведения видео она не запускается. Дополнительно используется штатное управление заставкой Samsung.
- Стартовый экран упрощён до названия приложения и индикатора загрузки.

## Возможности

- Каталог новинок, карточки тайтлов и списки серий.
- Просмотр серий встроенным плеером Samsung.
- Связанные тайтлы, если они доступны в каталоге.
- «Продолжить», «История» и «Избранное» после авторизации.
- Синхронизация истории, таймкодов, отметок просмотра и избранного.
- Ручное изменение статусов просмотра и управление избранным.

Без авторизации доступны публичные каталог и просмотр, но персональная история и прогресс не сохраняются.

## Поддерживаемые устройства

Samsung TV, Tizen 6.0 и новее. Проверено на Samsung Q80A (Tizen 6.0) и Q80B (Tizen 6.5). Доступность отдельных материалов зависит от сервиса AniLiberty.

## Установка

Скачайте `AniLiberty-TV-1.0.2.wgt` из [GitHub Releases](https://github.com/BrainFix/AniLiberty-TV-Tizen/releases/tag/v1.0.2).

Для установки рекомендуется использовать [актуальную версию Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung/releases/latest). Возможны другие способы установки WGT на Samsung.

## Управление

| Действие | Кнопки пульта |
| --- | --- |
| Перемещение и выбор элементов | Стрелки, OK |
| Возврат на предыдущий экран | Назад |
| Просмотр всех строк описания | «Подробнее», OK |
| Открытие действий серии или тайтла | Длительное OK (где предусмотрено) |
| Пауза и продолжение просмотра | OK, Play/Pause |
| Перемотка | ← / → |
| Скрыть или показать панель плеера | ↑ / ↓ |
| Пропустить опенинг или эндинг | OK или → при доступной подсказке |
| Запустить синхронизацию | Выбрать статус в верхней панели, OK |

## Работа с аккаунтом

В «Аккаунте» можно войти в AniLiberty, проверить подробности синхронизации, запросить обновление истории и выйти из аккаунта. При выходе локальные персональные данные текущего аккаунта удаляются с телевизора.

**Важно:** на чужом или общем телевизоре выходите из аккаунта после просмотра. Пока авторизация сохранена, другие пользователи телевизора могут получить доступ к личным данным аккаунта.

## Сборка из исходников

```bash
python3 scripts/собрать.py
python3 scripts/проверить.py
```

Скрипты создают и проверяют неподписанный WGT, включая семь встроенных SVG-значков синхронизации. Дополнительных Python-зависимостей нет.

## Проект и сервис

AniLiberty TV использует сетевые API и материалы сервиса AniLiberty. Для работы требуется доступ в интернет. Доступность каталога, воспроизведения и синхронизации зависит от сервиса.
