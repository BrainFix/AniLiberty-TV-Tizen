# AniLiberty TV

**AniLiberty TV 1.0.1** — приложение для просмотра аниме с сервиса AniLiberty на телевизорах Samsung с операционной системой Tizen 6.0 и новее.

Приложение ориентировано на управление обычным пультом телевизора: перемещение по карточкам и разделам, выбор серий, управление воспроизведением и возврат к просмотру.

**Неофициальный клиент.** AniLiberty TV — независимый проект. Он не является официальным приложением AniLibria или AniLiberty. Команды **AniLibria** и **AniLiberty** не участвуют в разработке, распространении и поддержке этого клиента.

Приложение создано с помощью **ChatGPT (OpenAI)**.

## Исправления версии 1.0.1

- Обложки тайтлов, кадры серий и заглушки заполняют свои области без искажения пропорций.
- Исправлено восстановление прокрутки и фокуса при возврате из карточки тайтла, в том числе с нижних рядов каталога.
- Если открытый тайтл исчез из раздела и раздел становится пустым, фокус возвращается к его кнопке в верхнем меню.
- Оптимизирована компоновка длинных списков серий без постоянного пересчёта всех изображений.

Исправления проверены на Samsung Q80A (Tizen 6.0) и Q80B (Tizen 6.5).

## Возможности

- Просмотр каталога новинок, карточек тайтлов, описаний и списков серий.
- Воспроизведение доступных серий с помощью встроенного видеоплеера телевизора.
- Переход между связанными тайтлами одного произведения, если связи доступны в каталоге.
- Разделы «Продолжить», «История» и «Избранное» для пользователей с аккаунтом AniLiberty.
- Синхронизация истории просмотра, прогресса по сериям и отметок о просмотре с аккаунтом AniLiberty.
- Ручное управление статусами просмотра серий и тайтлов в авторизованном режиме.
- Добавление и удаление тайтлов из избранного с синхронизацией по действиям пользователя.

**Без входа в аккаунт** доступны публичный каталог, страницы тайтлов, списки серий и просмотр доступных эпизодов. История, прогресс и избранное в этом режиме не сохраняются; для доступа к персональным разделам требуется авторизация.

## Поддерживаемые устройства

Телевизоры Samsung с **Tizen 6.0 и новее**. Работа приложения проверена на Samsung Q80A (Tizen 6.0) и Q80B (Tizen 6.5). Доступность конкретных серий и функций зависит от данных и работы сервиса AniLiberty.

## Установка

Рекомендуемый способ — [Apps2Samsung](https://apps2samsung.com/) **версии 2.8.3**.

1. Откройте файл [`AniLiberty-TV-1.0.1.wgt`](https://github.com/BrainFix/AniLiberty-TV-Tizen/releases/download/v1.0.1/AniLiberty-TV-1.0.1.wgt) в репозитории и скачайте его.
2. Установите и откройте [Apps2Samsung v2.8.3](https://github.com/Apps2Samsung/Apps2Samsung/releases/tag/v2.8.3) на компьютере или поддерживаемом устройстве.
3. Подключите телевизор и устройство с Apps2Samsung к одной локальной сети. Включите на телевизоре режим разработчика, следуя [инструкции Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung/wiki/FAQ).
4. В Apps2Samsung выберите телевизор и установку собственного файла приложения (`.wgt`). Укажите скачанный файл AniLiberty TV.
5. По завершении установки запустите AniLiberty TV на телевизоре.

Общее руководство по установке собственного `.wgt` приведено в [README Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung); порядок включения режима разработчика — в [FAQ Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung/wiki/FAQ).

**Также можно использовать любой другой удобный способ установки файлов `.wgt` на телевизоры Samsung с Tizen.**

## Управление

| Действие | Кнопка пульта |
| --- | --- |
| Перемещение по интерфейсу | Стрелки ↑ ↓ ← → |
| Выбор тайтла, серии или действия | OK |
| Возврат к предыдущему экрану | Назад |
| Открытие действий для серий и тайтлов | Длительное OK, где это предусмотрено |
| Пауза и возобновление воспроизведения | OK или Play/Pause |
| Перемотка | ← или → во время просмотра |

## Работа с аккаунтом

В разделе «Аккаунт» можно войти в учётную запись AniLiberty, посмотреть сведения о синхронизации и выйти из аккаунта. При выходе локальные данные просмотра и данные синхронизации текущего аккаунта удаляются с телевизора.

**Важно:** если вы пользуетесь приложением на чужом или общем телевизоре, обязательно выйдите из своего аккаунта после просмотра. Пока авторизация сохраняется, другие пользователи телевизора могут получить доступ к данным вашего аккаунта AniLiberty.

## Сборка из исходников

В корне репозитория находятся файлы приложения для Tizen Web Widget. Для создания архива WGT с этими файлами запустите:

```bash
python3 scripts/собрать.py
```

Скрипт создаёт файл `AniLiberty-TV-1.0.1.wgt` из `config.xml`, `index.html`, `app.js`, `style.css`, `card-layout.css`, `card-layout.js` и графических ресурсов. Для сборки требуется Python 3; дополнительных библиотек не нужно.

Чтобы проверить соответствие готового WGT исходникам и основные параметры `config.xml`, выполните:

```bash
python3 scripts/проверить.py
```

## Проект и сервис

AniLiberty TV использует сетевые API и материалы сервиса **AniLiberty**. Для работы требуется подключение телевизора к интернету. Доступность каталога и воспроизведения зависит от работы сервиса.
